# MarshMeg

Fullstack-разработчик с уклоном в backend и инфраструктуру. Делаю проекты целиком: API, клиентская часть, база данных, деплой и сопровождение.

## Стек

- **Backend:** Go (Gin, gRPC, REST), Python (Django, aiogram), NestJS
- **Frontend:** TypeScript, React, Next.js
- **Данные:** PostgreSQL, Redis
- **Инфраструктура:** Linux, Docker, Docker Swarm, Terraform + Proxmox VE, GitLab CI, GitHub Actions
- **Изучаю:** Kubernetes, Ansible, Prometheus, Grafana
